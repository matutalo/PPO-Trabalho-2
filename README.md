# PPO-Trabalho-2

 Fazer um site com uma API e WEB CRAWLER que procuram na steam (e se der tempo na epic games) jogos em promoção de tempo limitado que estão de graça, atualizando de hora em hora.

# Mostrar:
 Imagem
 Nome
 Preço préPromo
 00,00R$
 Link 
 Ativa (boolean)
 Plataforma de compra

 # Empatia:
 Site feito àqueles que gostariam de estar por dentro das ofertas gratuitas temporárias de jogos originalmente pagos.
 O site será atualizado a cada hora para verificar e carregar possíveis promoções de uma ou múltiplas plataformas.

 # Definição:
 
 ## O que aprender:
 Web Crawler
 APIs
 
 O problema a ser resolvido será a dificuldade de acesso a essas informações, a falta de intuição e simplicidade na hora de procurar promoções com preço ajustado a 00,00R$.

 # Ideação:

 ## As ideias são: 
 Mostrar o jogo com suas informações completas, indexar o link oficial de acesso ao download, criar um ambiente agradável e de fácil acesso para descobrir as ofertas limitas.

 ## Resolução do Problema:
 Trazer as informações dos donativos ao usuário com apenas um único click, sem login, sem ter que pesquisar e alterar filtros de pesquisa. O site fará todo o trabalho por você a
 cada 60 minutos, ilimitadamente.

 # Prototipação:

 Já está simples e tudo será feito no tempo de 3 meses corretamente.

 # Teste:

 Testar 5 computadores diferentes, de diferentes redes, depois de horas, dias ou semanas, para testar a eficácia do site.
